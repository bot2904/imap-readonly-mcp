Audit functionality that is documented but not implemented, incomplete, or no longer needed, and decide whether to implement, remove, or update documentation.

Examples to investigate:
- POP3-related functionality
- Gmail-related functionality

Suggested steps:
1. Search docs, examples, and code for documented features with missing implementations.
2. Verify whether each feature is still needed.
3. Remove dead/unneeded docs or code references, or create implementation follow-up tasks where appropriate.
4. Ensure docs accurately reflect supported functionality.
